Getting started

Install Sidea on macOS

You'll need an Apple Silicon Mac running macOS 26.2 or later, with about 8 GB free for the local model. No developer tools are needed.

  1. Open the newest published prerelease and download Sidea-Preview-arm64.dmg from Assets.
  2. Quit any running Sidea app. Open the DMG and drag Sidea Preview to Applications.
  3. Open Sidea Preview from Applications. The preview is self-signed and unnotarized. If you trust the download and macOS cannot verify it, follow Apple's Open Anyway instructions.
  4. Choose Download local model (~6.8 GB), then select Unlock Sidea when setup finishes.
