# Sidea Preview

Source for the [Sidea preview website](https://agonza1.github.io/sidea-preview/).
The site is plain HTML and CSS served by GitHub Pages. This repository also
collects Windows and Linux requests in Issues; use synthetic examples and keep
patient information out of public reports.

Sidea's Mac installer is distributed to invited testers through the private
[Sidea-pro releases](https://github.com/agonza1/Sidea-pro/releases).

Write for healthcare professionals who may never have used GitHub. Lead with
what Sidea helps them do, use the words they see on their Mac, and keep
troubleshooting separate from the main steps. When updating the installer,
update the download button and the fallback release link in `index.html`.
